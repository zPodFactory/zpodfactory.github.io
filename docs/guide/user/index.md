# User Guide

Once an administrator has set up the factory, you manage your zPods from the **[Web UI](web-ui.md)** (zpodweb, at `http://<appliance-ip>:8500`) or from the **zcli** command line. Both use the same zPod API, so pick whichever suits the task: the Web UI for day-to-day work and a visual view of networks and storage, `zcli` for scripts and automation (see [Set up the zPod CLI (zcli)](../zcli.md)).
